# Exámenes Anteriores ITCR - Organizador

Esta herramienta web está diseñada para agilizar el procesamiento, renombrado y edición de archivos PDF de exámenes antes de integrarlos al repositorio de archivos de [Exámenes Anteriores ITCR](https://github.com/rgdan/examenes-anteriores-itcr-archivos).

---

## Uso de la Herramienta

Para utilizar el organizador y preparar nuevos exámenes para el proyecto, visite la aplicación web alojada en:

**[Exámenes Anteriores ITCR - Organizador](https://example.com)**

---

## ¿Cómo contribuir?

Si desea agregar nuevos exámenes o corregir metadatos existentes, recuerde que **los archivos finales deben subirse al repositorio de archivos** ([examenes-anteriores-itcr-archivos](https://github.com/rgdan/examenes-anteriores-itcr-archivos)) y no al repositorio del código web o a este.

Antes de realizar cualquier aporte, es **indispensable** que consulte la documentación oficial en la Wiki del repositorio principal:

* **[Guía de Contribución](https://github.com/rgdan/examenes-anteriores-itcr/wiki/Cómo-contribuir):** Pasos detallados para subir sus aportes.
* **[Nomenclatura y Convenciones](https://github.com/rgdan/examenes-anteriores-itcr/wiki/Nomenclatura-y-Convenciones):** Reglas para nombrar los archivos PDF y organizar los metadatos.
